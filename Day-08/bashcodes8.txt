Q2 - Factorial
output : Factorial of 5 is : 120


{ ~ }  » touch fact.sh
{ ~ }  » chmod 777 fact.sh
{ ~ }  » vi fact.sh
echo "Enter the value: "
read num
fact=1
for((i=1; i<=num; i++))
do
fact=$(($fact*$i))
done
echo "Factorial of " $num " is: "$fact

{ ~ }  » ./fact.sh
Enter the value:
5
Factorial of  5  is:  120
